## 四、卡最久的四个点（按耗时排序）

1. **`uv.lock` 把境外地址写死，导致换源无效（最久，约 40min）**
   `uv.lock` 里 1060 处 `files.pythonhosted.org`。`--frozen` 的语义是"严格照 lock 执行"，所以**只加 `-i` 换源完全无效**。必须 `UV_DEFAULT_INDEX=... uv sync`（不带 `--frozen`）让它重新解析。
   → 这条对 W3 / 任何国内部署都成立，已写进 README。

2. **阿里云镜像加速器对 `library/python` 返回 404（约 15min）**
   报错 `failed to resolve reference ... not found`，看起来像 Dockerfile 错，实际是加速器没同步多架构镜像。换 `docker.m.daocloud.io` 立刻通。

3. **ECS 创建时误选密钥对 → `Permission denied (publickey)`（约 10min）**
   括号里是 `publickey` 而非 `password`，说明服务端只认密钥、不认密码。解法：控制台「重置实例密码」+ **重启**（不重启不生效）。

4. **"假 000"（约 10min）**
   `$WS` 变量在交互式粘贴里丢失 → URL 变成 `/embeddings` → curl 报 malformed，`-s` 吞掉错误 → 只看到 `HTTP 000`。**误判为"端点挂了"。**
   解法：测试脚本写成文件再执行，不要在命令行里靠变量传递。

## 五、五个已经能吃住的技术判断（W2 版）

**1. `tail -f` 和 `tail -F` 是两个东西。**
文件不存在时 `-f` 直接退出（`no files remaining`），`-F` 会等。生产环境一律 `-F`。

**2. 容器是可丢弃的，数据必须落在外面。**
`docker run` 不加 `-v`，容器一退 `out/*.json` 就没了。同理：容器里装的 `logs/` 也不是你的。

**3. 密钥要三层防护，任意一层都不该单独依赖。**
白名单 COPY（构建时）+ `.dockerignore`（传输时）+ `--env-file`（运行时）。三层都做，因为人会手滑，而泄露不可逆。

**4. `HTTP 000` 不是 `404`。**
000 = 连 HTTP 响应都没拿到（DNS/TCP/TLS/超时）；404 = 服务端明确说没有。判断"服务挂了"之前，先分清是哪一层。

**5. 免费额度是排期约束，不是省钱技巧。**
qwen3.8-flash 额度 11-25 到期，embedding/rerank 11-30 到期。**12 月起按量付费**——所以 W3–W5 的评测主体必须 11 月内跑完，否则成本从 0 变成每天几十块。
