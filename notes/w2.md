### 卡点与解法（四条，全是真踩过的）

1. **`docker build` 报 `failed to resolve reference "docker.io/library/python:3.12-slim": not found`**
   → 不是 Dockerfile 的问题，是阿里云加速器没同步这个多架构镜像。换 `docker.m.daocloud.io` 即可。
2. **`pip install uv` 停在一行没输出、看着像卡死**
   → 非交互环境下 pip 不打印进度条，实际在 295kB/s 下载，60 秒后自己完成。**判断卡死不能只看屏幕**，用 `docker ps -a` 看有没有中间容器在跑。
3. **换 PyPI 镜像对 `uv sync --frozen` 无效**
   → `uv.lock` 里 1060 处 `files.pythonhosted.org` 地址被写死；`--frozen` = 严格照 lock 执行，所以仍去境外下。**必须同时去掉 `--frozen`**（本次改动：`UV_DEFAULT_INDEX=... uv sync --no-dev`）。周六裸机部署会再撞一次，README 要写。
4. **`uv run` 启动时自动补装 4 个 dev 包（`Installed 4 packages in 6ms`）**
   → build 用 `--no-dev`，runtime 的 `uv run` 默认连 dev 组一起同步 → 镜像"自愈"但可能触发意外联网。定稿写法：`ENTRYPOINT ["uv","run","--no-sync","llm-cli"]`（ENTRYPOINT 是最后一行，改它只重跑 1 个 Step）。

### 两个必须带进 W3 的硬约束（比"走哪个端点"更重要）

**① embedding 不是确定性的 —— 向量必须落盘复用**

同一句话跑两次（同一端点、同一模型、同一参数）结果不同：

```
最大绝对差 0.00738525390625
平均绝对差 0.0012098981533199549
余弦相似度 0.9987467884277662
```

余弦 0.9987 已经超出 float32 精度噪声（那应该在 1e-7 量级），所以这是**服务端真实存在的数值非确定性**。
→ W3 的向量库**必须入库一次、落盘（npy/sqlite）后复用**，不能每次评测重算，否则同一份配置跑两次分数会漂，评测结论不可信。

**② 免费额度 11 月底到期 —— 评测主体必须 11 月内跑完**

| qwen3.7-text-embedding-flash | 999.94K / 1M | 2026-11-30 | 32 |

额度几乎没动（不到 0.1%），够用；**但 12 月起就是按量付费**。所以 W3–W5 的评测要在 11 月内把主体跑完，12 月只做小规模回归。

### 三个"假信号"，记下来防复发

1. **假 000**：`$WS` 变量在交互式粘贴里丢了 → URL 变成 `/embeddings` → `curl` 报 malformed、`-s` 吞掉错误 → 看到 `HTTP 000`，误判"端点挂了"。**结论：变量写进脚本文件再执行，别在命令行里靠变量传递。**
2. **假 401**：`sk-ws-` 开头的 116 位 key 并非"只能用于 ws- 端点"，标准端点同样有权限。**别用 key 的前缀推断它的作用域。**
3. **假不同**：用 `==` 比较浮点向量必然报"不同"，必须量化（最大绝对差 + 余弦）。**判据不同，结论就相反。**
